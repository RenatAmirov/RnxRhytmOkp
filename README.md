# Ритм ОКП

Локальное веб-приложение для оперативно-календарного планирования дискретного производства. Интерфейс на русском языке.

## Запуск

Нужен Node.js 24 или новее.

```powershell
npm ci
npm run build
npm start
```

Откройте [http://127.0.0.1:4280](http://127.0.0.1:4280). Для разработки используйте `npm run dev`. Чтобы выбрать другой порт для собранного приложения, задайте переменную окружения `PORT`.

## Работа в приложении

1. В справочниках добавьте рабочие центры, а на складе — материалы. Задайте изделия, операции, нормы времени и расход на единицу.
2. Создайте производственный заказ. Планировщик распределит операции по сменам с учётом последовательности маршрута, приоритета заказа и конечной мощности каждого центра.
3. Проверьте сроки на диаграмме Ганта. В диспетчерской запустите операцию и зарегистрируйте годные изделия и брак.
4. Проверьте остатки, складские движения и журнал качества. Запуск первой операции заказа списывает материал по сохранённой норме.

Планирование использует рабочие дни с понедельника по пятницу и одну смену с 08:00 по самарскому времени. Длительность смены задаётся в рабочем центре. В первой версии изделие использует один основной материал и последовательный технологический маршрут.

## Данные

При первом запуске создаётся `data/ritm.sqlite` с демонстрационной площадкой. Путь к базе меняется переменной `RITM_DB`. Чтобы начать с пустой площадки, укажите новый файл базы и режим `empty` перед запуском:

```powershell
$env:RITM_DB = 'data/production.sqlite'
$env:RITM_SEED = 'empty'
npm start
```

Приложение рассчитано на локальное использование. Авторизация пользователей и интеграция с 1С или ERP в эту версию не входят.
